# PaperMod Subscribe

Email subscriptions for Hugo sites that use the [PaperMod](https://github.com/adityatelange/hugo-PaperMod) theme and are hosted on [Cloudflare Pages](https://pages.cloudflare.com/).

It adds a signup form under each post. Readers confirm their address by email, then get added to a segment in [Resend](https://resend.com/). To email them when you publish, see [Paperboy](https://github.com/ayonkhan/paperboy).

**Work in progress.** It's running on my blog, [ayonkhan.ca](https://www.ayonkhan.ca/), and I'm moving the code here so others can use it. Setup steps will follow once it's ready.
